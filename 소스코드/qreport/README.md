# 시장 품질 리포트 (qreport)

## 이 프로그램이 하는 일

회사의 냉장고 시장 품질 엑셀(RawData·생산량·판매량)을 **수정 없이 그대로** 올리면, 이 PC 안에서 불량률 분석과 관리 기준(R1~R8) 판정을 하고 경고 카드, 차트, Word/PDF 보고서를 한 화면에서 만들어 줍니다.
인터넷에 연결하지 않으며 데이터는 이 PC 밖으로 나가지 않습니다.
월간 보고서 작성에 쓰던 시간을, 판정 확인과 중점 관리 이슈·개선 계획 작성에 쓰도록 하는 것이 목적입니다.

## 처음 설치

1. Python 3.12 이상을 설치합니다 (python.org, 3.13에서 검증). 설치 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 프로그램 폴더를 **OneDrive·바탕 화면 밖의 짧은 위치**(예: `C:\qreport`)에 복사합니다. OneDrive 폴더에 두면 동기화로 설치가 느려지거나 실패할 수 있습니다.
3. 그 폴더의 `설치.bat`을 더블클릭합니다. 몇 분 걸리며, "설치가 완료되었습니다"가 나오면 끝입니다. (한 번만 하면 됩니다.)

## 매달 사용 순서

1. `실행.bat`을 더블클릭합니다. 검은 창이 뜨고 잠시 뒤 브라우저에 화면이 열립니다. 검은 창은 사용이 끝날 때까지 닫지 마세요.
2. 왼쪽 사이드바에서 엑셀을 올립니다. 파일이 여러 개여도 한꺼번에 올릴 수 있습니다.
3. **기준월**을 확인합니다. 기본값은 자료에 있는 가장 최근 발생월이고, 바꾸면 그 달 기준으로 다시 계산합니다.
4. 맨 위 판정(개선 필요 / 주의 / 정상)과 **경고 카드**를 확인합니다. 카드의 "근거 차트 보기"를 누르면 해당 차트가 아래에 나옵니다.
5. **작성란**에 중점 관리 이슈(8장)와 개선 계획(9장: 담당·일정·대책)을 적습니다. 입력하면 자동 저장됩니다.
6. 맨 아래에서 **Word / PDF / 차트 PNG 묶음(ZIP)** 을 내려받습니다.
7. 끝나면 브라우저 탭과 검은 창을 닫습니다.

## 화면 설명

사이드바
- **엑셀 올리기**: RawData·생산량·판매량 엑셀 (xlsx, xlsm).
- **기준월**: 분석 기준이 되는 달. 엑셀을 올리면 나타납니다.
- **AS 처리비 (원/건)**: 입력하면 예상 비용을 계산합니다. 0이면 비용 추정을 표시하지 않습니다.
- **지난 작업**: 최근 8건. 누르면 그때의 파일, 기준월, 작성 내용을 다시 불러오고, 그 뒤에 룰을 바꿨더라도 그때의 룰 버전으로 같은 결과를 보여 줍니다 (화면 위 "룰 vN" 표시). 새 엑셀을 올리면 현재 룰로 분석합니다.

본문 (위에서 아래로)
- **검증 요약**: 읽은 시트와 행 수, 제외·검토된 행. 펼치면 제외 사유와 Total 차이가 보입니다.
- **판정 박스**: 개선 필요 / 주의 / 정상, 예상 추가 접수 범위, 예상 비용, 최근 12개월 시장 불량률.
- **경고 카드**: 걸린 룰(R1~R8), 대상, 설명, 근거 차트 버튼.
- **차트**: 모델을 고르고 차트를 선택합니다 (관리도, MIS 곡선, 파레토, 히트맵, 추이 등).
- **작성란**: 이슈 글, 개선 계획 표.
- **내려받기**: Word, PDF, ZIP.

## 판정 기준 요약

기본값 기준입니다. 값은 설정 페이지에서 바꿉니다. 전체 판정은 "높음"이 하나라도 있으면 **개선 필요**, "중간"이 있으면 **주의**, 아니면 **정상**입니다.

| 룰 | 이름 | 조건 (기본값) | 심각도 |
|---|---|---|---|
| R1 | 관리도 이탈 | 최근 6개월(기준월까지) 생산월 중 불량률이 관리상한(3σ)을 넘고 건수가 3건 이상. 전체와 모델별 | 높음 |
| R2 | 연속 상승 | 최근 6개월 안에 중심선 위 점이 9개월 연속 | 중간 |
| R3 | 초기 불량형 | 와이블 형상모수 β의 신뢰구간 상한이 1 미만 (구간 S1·S2 또는 모델별 최근 6개월) | 높음 |
| R4 | 수준 상승 | 모델별 최근 6MIS 불량률이 이전 6MIS의 1.5배 이상이고, β 신뢰구간이 1을 포함 | 높음 |
| R5 | 유형 급증 | 기준월 불량 유형 건수가 최근 6개월 평균의 1.5배 이상이고 8건 이상 | 중간 |
| R6 | 전년 대비 악화 | 최근 12개월 불량률이 직전 12개월보다 높고 유의수준 0.05에서 유의 (전체·모델·유형별) | 중간 |
| R7 | 히트맵 주의 | 생산월×MIS 히트맵에서 기준선을 넘는 칸이 있음 | 낮음 |
| R8 | 목표 초과 | 모델의 최근 12개월 시장 불량률이 설정한 목표 불량률보다 높음 (목표를 등록한 모델만) | 낮음 |

## 설정 바꾸는 법

화면 왼쪽 위 메뉴에서 **설정** 페이지로 갑니다.

- **룰 값**: 숫자를 고치고 "룰 저장 (새 버전)"을 누릅니다. 저장하면 새 룰 버전(v2, v3...)이 생기고 이후 분석에 쓰입니다. 이미 만든 지난 작업은 그때의 버전 기록이 그대로 남습니다. 값이 그대로면 새 버전이 생기지 않습니다.
- **모델별 목표 불량률**: 표에 모델명과 목표(%)를 적고 "목표 저장". '전체'라고 적으면 전체 목표입니다. 행을 지우고 저장하면 목표가 삭제됩니다. R8에 쓰입니다.
- **열 이름 사전**: 엑셀 열 제목이 어떤 항목(모델, 생산월, 발생월, 불량 유형, 사용개월)인지 알려주는 표입니다. 행을 추가하고 "사전 저장".

## 엑셀 양식이 바뀌었을 때

열 제목이나 시트 이름이 바뀌어 프로그램이 알아보지 못하면 분석 대신 **매핑 확인 화면**이 나옵니다.

1. 시트마다 역할(생산량 / 판매량 / 불량 내역 / 무시)을 고릅니다.
2. 불량 내역 시트는 모델·생산월·발생월·불량 유형에 해당하는 열을 고릅니다.
3. "열 이름 사전에 추가"가 체크되어 있으면 다음부터는 자동으로 알아봅니다. (그대로 두기를 권합니다.)
4. "확정하고 다시 분석"을 누릅니다.

사전은 설정 페이지에서 직접 추가·삭제할 수도 있습니다.

## 데이터가 저장되는 곳

프로그램 폴더가 아니라 이 PC의 사용자 폴더 안 **`%LOCALAPPDATA%\qreport\data`** 에 저장됩니다 (보통 `C:\Users\<사용자>\AppData\Local\qreport\data`, 처음 실행할 때 자동으로 만들어짐). OneDrive 같은 클라우드 동기화 폴더 밖이므로 회사 자료가 PC 밖으로 나가지 않습니다.
- `qreport.db`: 작업 기록, 룰 버전, 작성란 내용, 목표, 열 이름 사전, 다운로드 기록
- `jobs\` 안의 작업별 폴더: 그때 올린 엑셀 원본 사본

탐색기 주소창에 `%LOCALAPPDATA%\qreport` 를 입력하면 바로 열립니다.

**백업**: 프로그램(검은 창)을 끈 상태에서 `%LOCALAPPDATA%\qreport\data` 폴더를 통째로 사내 백업 위치에 복사해 두면 됩니다. 복원은 그 폴더를 다시 같은 자리에 덮어쓰면 됩니다. 다른 위치에 저장하려면 환경변수 `QREPORT_DATA`에 폴더 경로를 지정합니다.
회사 자료가 들어 있으므로 이 폴더를 메일이나 외부 저장소·OneDrive에 올리지 마세요.

## 문제 해결

- **설치.bat에서 "Python이 설치되어 있지 않습니다"**: Python 설치 때 PATH 체크를 하지 않은 경우입니다. Python을 지우고 다시 설치하면서 "Add python.exe to PATH"를 체크하세요.
- **설치 중 오류 (긴 경로)**: 폴더 위치가 너무 깊으면 실패할 수 있습니다 (`pip` 오류에 "Long Path"가 보임). 폴더를 `C:\qreport` 처럼 짧은 위치로 옮겨 다시 `설치.bat`을 실행하세요.
- **설치가 인터넷 때문에 실패**: 설치할 때만 인터넷이 필요합니다 (프로그램 사용 중에는 필요 없음). 사내망이면 프록시·보안 설정을 확인하세요.
- **브라우저가 저절로 안 열림**: 검은 창이 떠 있는 상태에서 브라우저 주소창에 `http://localhost:8501` 을 입력하세요.
- **"Port 8501 is not available" / 포트 사용 중**: 실행 창이 이미 떠 있는 것입니다. 기존 검은 창을 닫고 다시 실행하거나, `http://localhost:8501`을 열어 보세요. 다른 포트를 쓰려면 `.venv\Scripts\streamlit run src\qreport\app\main.py --server.port 8502`.
- **"시트 역할이나 열 이름을 알 수 없습니다"**: 위 "엑셀 양식이 바뀌었을 때"를 따라 지정하세요.
- **"… 시트를 찾지 못했습니다"**: RawData·생산량·판매량 중 하나가 올린 파일에 없습니다. 메시지 아래의 시트별 판별 결과를 보고, 빠진 시트가 든 파일을 함께 올리세요.
- **"같은 파일이 두 번 올라왔습니다" / "여러 시트의 데이터가 겹쳐"**: 같은 생산량(또는 판매량) 자료가 두 번 들어가 합산되면 숫자가 부풀려지므로 멈춥니다. 메시지에 나온 파일·시트 중 하나를 빼고 다시 올리세요.
- **"분석 중 오류가 발생했습니다"**: "자세한 오류 내용"을 펼쳐 내용을 관리자에게 전달하세요. 올린 엑셀이 열린 채 편집 중이거나 암호가 걸려 있지 않은지도 확인하세요.
- **화면이 멈춘 것 같음**: 큰 파일은 분석과 차트 생성에 수십 초 걸릴 수 있습니다 (기업 엑셀 기준 전체 처리 1분 이내).

## 관리자용

폴더 구조
- `설치.bat` / `실행.bat`: 설치(가상환경 `.venv` 만들고 패키지 설치) / 실행.
- `.streamlit\config.toml`: 사용 통계 전송 끄기 (`gatherUsageStats = false`), 화면 테마(강렬한레드)와 폰트 설정.
- `src\qreport\app\static\`: 화면 제목용 폰트(Bithumb Gothic). 인터넷 없이 이 PC에서만 불러옵니다.
- `src\qreport\app\`: 화면 (`main.py` 분석 화면, `settings.py` 설정, `viewmodel.py` 화면용 계산, `common.py` 저장소 위치).
- `src\qreport\ingest\`: 엑셀 읽기와 검증 (시트 역할 판별, 열 이름 사전, 제외 행).
- `src\qreport\metrics\`: 관리도, 와이블, 코호트(MIS), 히트맵, 급증, 전년 대비, 시장 불량률 계산.
- `src\qreport\rules\`: `engine.py` R1~R8 판정, `comments.py` 한글 코멘트 문장.
- `src\qreport\ruleset.py`: 룰 값 기본값(`RuleSet`).
- `src\qreport\pipeline.py`: 읽기부터 판정까지 이어주는 `analyze()`.
- `src\qreport\render\`: 차트, Word(`docx_report.py`), PDF(`pdf_report.py`), PNG ZIP(`bundle.py`).
- `src\qreport\templates\report.docx`: Word 양식. `scripts\build_template.py`로 다시 만듭니다.
- `src\qreport\store\db.py`: SQLite 저장소.
- `tests\`: 테스트. `tests\synth.py`는 가짜 엑셀 생성기.

`.bat` 파일은 **CP949(ANSI)로 저장해야 합니다** (줄바꿈 CRLF). UTF-8로 저장하면 검은 창의 한글이 깨지고 명령이 실패할 수 있습니다.

설치는 `requirements-lock.txt`(검증된 패키지 버전 목록)를 제약 조건으로 써서 항상 같은 버전을 설치합니다 (`pip install -c requirements-lock.txt -e .[dev]`). 패키지를 올릴 때는 새 버전으로 테스트를 통과시킨 뒤 `.venv\Scripts\pip freeze --exclude-editable > requirements-lock.txt`로 다시 만듭니다.

테스트 실행 (전체 약 2~3분)

```
.venv\Scripts\python -m pytest
```

회사 엑셀을 `tests\data\company.xlsx`에 두면 실제 자료로 하는 정합성 테스트와 처리 시간 테스트가 함께 돕니다. 없으면 그 테스트들은 건너뜁니다. 이 파일은 `.gitignore`에 있지만 **절대 커밋하거나 외부에 올리지 마세요.**
