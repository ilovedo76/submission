# 시장품질 리포트 자동화 — 결과 보고서 & 실행 안내

냉장고 필드 불량 엑셀을 **고치지 않고 그대로** 올리면, 판정·경고·결재용 보고서(Word/PDF)까지 한 번에 나오는 품질 분석 도구입니다.
제출물은 **대시보드(품질 현황판)** 와 **체험형 MVP** 두 가지이며, 링크 하나로 둘 다 열립니다.

> **바로 열기:** https://claude.ai/artifact/8SRV2Mp7ymJz2KA8vAq6AF
> (claude.ai 로그인 필요 · 설치 불필요 · 폴더의 `품질 현황판 + 체험형 MVP 열기` 바로가기를 더블클릭해도 됩니다)

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 문제 | 현행 엑셀은 판정 기준선이 없고(차트 5개 중 0개), 모델별 분모가 틀려 불량률이 최대 6.4배 과소. '25년 하반기 초기 불량 급증을 놓침 |
| 해결 | 엑셀 업로드 1번 → 통계 판정(R1~R8) → 경고 카드·차트 → Word/PDF/차트 ZIP. 매달 수작업 9단계 → 1단계 |

## 2. 실행 방법

### 2-1. 웹 (심사용 — 설치 없음)

1. 위 링크를 claude.ai에 로그인한 상태에서 엽니다. 첫 화면은 **대시보드**입니다.
2. 위쪽 **"체험형 MVP 열기 →"** 를 누릅니다.
3. **"샘플 데이터로 해보기"** 를 누르거나, 이 폴더의 `체험용_가상_샘플_데이터.xlsx` 를 올립니다.
   - 첫 실행 때 분석 엔진을 불러오느라 **20~40초** 걸립니다. 이후 분석은 몇 초입니다.
4. 결과 확인: 종합 판정 → 경고 카드("근거 차트 보기") → 차트(모델 선택) → 작성란(이슈·개선 계획).
5. **Word / PDF / 차트 ZIP** 버튼으로 보고서를 내려받습니다.
6. 대시보드로 돌아가 새로고침하면 방금 분석한 결과가 **업로드 이력**에 추가되어 있습니다.

- 샘플은 **가상 데이터**이며 화면·보고서에 "가상 데이터"로 표시됩니다.
- 올린 엑셀 원본은 브라우저 밖으로 나가지 않고, 결과 요약만 대시보드에 저장됩니다.
- 결과 저장은 "참여(Contributor)" 권한이 있을 때만 됩니다. 보기 권한만 있으면 분석·다운로드는 되고 저장 안내만 나옵니다.

### 2-2. 데스크톱 프로그램 (사내 PC용, 선택)

`소스코드/qreport/` — 인터넷 없이 PC 한 대에서 쓰는 버전입니다.

1. Python 3.12 이상 설치 (설치 화면에서 **"Add python.exe to PATH" 체크**).
2. `qreport` 폴더를 짧은 경로(예: `C:\qreport`)에 복사합니다.
3. `설치.bat` 더블클릭 (처음 한 번, 몇 분).
4. `실행.bat` 더블클릭 → 브라우저에 화면이 열립니다. 엑셀을 올리면 웹과 같은 판정·보고서가 나옵니다.
   - 지난 작업 다시 열기, 판정 룰 설정 변경, 작성란 자동 저장 기능이 추가로 있습니다. 자세한 내용은 `소스코드/qreport/README.md`.

## 3. 주요 결과 (기업 데이터 '24.01~'25.12, 기준월 25.12)

| 지표 | 기획서 | 프로그램 계산 |
|---|---|---|
| 1MIS 중심선 | 0.035% | 0.035% |
| 25.12 생산분 1MIS / 관리상한 | 0.136% / 0.070% | 0.136% / 0.070% → **이탈** |
| 양문형 25.12 1MIS (모델별 분모) | 0.241% | 0.241% (현행 엑셀 0.038%) |
| 시장 불량률 '24 → '25 | 0.122% → 0.191% | 0.122% → 0.191% (+57%) |
| 와이블 β '25.11~12 | 0.41 (0.23~0.74) | 0.41 (0.23~0.74) → **초기 고장형** |
| 김치 6MIS '24 → '25 | 0.167% → 0.315% | 0.167% → 0.315% → **수준 상승형** |
| 추가 접수 예측 (25.08~12 생산분) | 101~114건 | 101~114건 |

자동 생성되는 요약 코멘트(일부):

> **종합 판정: 개선 필요 (경고 10건)**
> 1. 25.12 생산분 1MIS 0.136%(36건)로 관리상한 0.070% 초과. 25.11(0.083%, 23건)에 이어 2개월 연속 이탈.
> 2. 25.12 모델별 1MIS: 4Door 0.223%(상한의 2.0배), 양문형 0.241%(1.7배), 2Door 0.093%(1.4배) 초과.
> 3. 25.11~12 생산분 β 0.41(95% CI 0.23~0.74)로 초기 고장형 확정. 공정 변경·부품 로트·협력사 변경 이력 점검 권고 (가설)
> 4. 김치 6MIS 0.315%('24 0.167%의 1.9배), β ≈ 1로 패턴 유지·수준 상승. 설계·부품 신뢰성 점검 권고 (가설)

## 4. 기능

**대시보드 (품질 현황판)** — 한 장 개요형
- 카드: 종합 판정, 경고 수, 최근 12개월 시장 불량률(전년 대비), 기준월 1MIS, 추가 접수 예상
- 차트: 시장 불량률 추이, 1MIS P 관리도(중심선·관리상한), 생산월×MIS 히트맵(관찰 전 칸 회색), 유형 파레토(80% 선), 모델×유형 증감
- 경고 목록, 업로드 이력(누가·언제·판정), 모델·기간 필터, 업로드 선택

**체험형 MVP**
- 엑셀 업로드 또는 샘플 → 판정·경고 카드·근거 차트 → 작성란 → Word/PDF/차트 ZIP
- 분석 결과는 자동으로 대시보드에 반영

**판정 룰 (기본값)**

| 룰 | 내용 | 심각도 |
|---|---|---|
| R1 | 최근 6개월 생산분 1MIS가 관리상한(3σ) 초과, 3건 이상 | 높음 |
| R2 | 중심선 위 9개월 연속 | 중간 |
| R3 | 와이블 β 신뢰구간 상한 < 1 (초기 고장형) | 높음 |
| R4 | 6MIS 1.5배 이상 상승 + β ≈ 1 (수준 상승형) | 높음 |
| R5 | 기준월 불량 유형 급증 (6개월 평균의 1.5배, 8건 이상) | 중간 |
| R6 | 전년 대비 악화 (2-비율 검정 p < 0.05) | 중간 |
| R7 | 히트맵에서 전년 기준 초과 칸 | 낮음 |
| R8 | 목표 불량률 초과 (목표 등록 시) | 낮음 |

높음이 하나라도 있으면 **개선 필요**, 중간만 있으면 **주의**, 없으면 **정상**.

## 5. 구조와 기술

```
엑셀 ─▶ [분석 엔진 qreport (Python)] ─▶ 판정·경고·차트·Word/PDF
              │                      │
      데스크톱 앱(Streamlit)     웹 MVP (브라우저 안 Python = Pyodide)
                                     │ 결과 요약 저장
                                     ▼
                               대시보드 (ECharts)
```

- **분석 엔진 하나를 데스크톱과 웹이 함께 사용**합니다. 웹에서 통계를 다시 만들지 않아 같은 파일이면 같은 판정·같은 문장이 나옵니다 (자동 비교 테스트로 확인).
- 언어·라이브러리: Python (pandas, SciPy, Matplotlib, ReportLab, docxtpl), Streamlit, Pyodide, ECharts.
- 검증: 기획서 수치 재현, 모델별 분모, 관찰 전 마스킹, 이상 패턴 6종 탐지, 데스크톱↔웹 결과 일치 테스트.

## 6. 한계와 다음 단계

- 사용 6개월까지의 데이터라 12개월 이후 마모 고장은 판단하지 않습니다. 생산월을 사용 시작 시점으로 가정합니다(판매 지연 미반영).
- 원인 문장은 모두 **(가설)** 이며, 최종 판단은 엔지니어 작성란에서 합니다.
- 웹 MVP는 열 이름이 기업 양식과 다르면 안내 메시지만 보여 줍니다(데스크톱 앱은 열 매핑 화면 제공).
- 다음 단계: 출고·설치일 연동으로 판매 지연 보정, 사내 서버 배포와 권한 체계, 회사 보고서 양식 적용.
